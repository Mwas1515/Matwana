# Matwana

**Matwana** is a Kenyan-inspired matatu/nganya simulation game built with Python. The player manages a matatu, transports passengers, earns money, completes routes, upgrades their vehicle, and builds their reputation.

## Features

* Player profile and progression
* Matatu management
* Multiple routes
* Passenger system
* In-game economy using Kenyan Shillings (KSh)
* Fuel management
* Vehicle maintenance
* Random events
* Reputation and XP system
* Levels and progression
* Matatu upgrades and customization
* Achievements and statistics
* SQLite save/load system
* CustomTkinter desktop GUI

## Technologies

* **Python**
* **Object-Oriented Programming (OOP)**
* **SQLite3**
* **CustomTkinter**
* **Git & GitHub**
* **PyInstaller** *(for the final executable)*

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Mwas1515/Matwana.git
```
```
cd matwana
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

### 3. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux/macOS:**

```bash
source venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the game

```bash
python app.py
```
